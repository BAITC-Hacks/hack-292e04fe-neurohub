# NeuroHub — прогнозирование выработки ВЭС

Исследовательский ML-проект для прогноза нормализованной активной мощности ветроэлектростанции (ВЭС). Решение предназначено для специалистов, которым нужно оценить будущую выработку по истории работы станции и погодным данным — например, для планирования генерации и дальнейшего расчёта почасовой энергии.

Основной реализованный сценарий строит почасовой прогноз с помощью CatBoost. В репозитории также есть эксперименты с RNN, LSTM и SARIMA.

## Что реализовано

- аудит качества исходных данных: пропуски, дубликаты, временной шаг и физические ограничения;
- очистка и агрегация 10-минутных измерений до одного часа;
- автоматическое распознавание русских и распространённых английских названий полей;
- построение погодных и календарных признаков;
- временное разделение данных без перемешивания на train, validation и test;
- сравнение CatBoost с двумя базовыми подходами: средним по train и эмпирической кривой мощности;
- оценка регрессии по MAE, RMSE, nMAE, Bias и R²;
- опциональная walk-forward-валидация через `TimeSeriesSplit`;
- сохранение обученных моделей и CSV с прогнозами;
- получение почасового прогноза погоды Open-Meteo и расчёт прогноза на 48 часов;
- отдельные эксперименты с SimpleRNN, многомерной RNN, LSTM и SARIMA;
- графики обучения, факта и прогноза, остатков, важности признаков и ошибок по режимам.

## Как работает решение

Основной сценарий находится в [`lerning_catboost.ipynb`](lerning_catboost.ipynb):

1. Ноутбук читает CSV/XLSX с временной меткой, скоростью ветра, температурой и фактической нормализованной мощностью.
2. Проверяет качество данных и отбрасывает физически невозможные значения.
3. Агрегирует измерения с шагом 10 минут в почасовые значения. Для часа принимаются не менее 5 из ожидаемых 6 измерений.
4. Создаёт признаки из скорости ветра, температуры, их взаимодействия и календарных циклов.
5. Последовательно по времени делит данные в пропорции 70% / 15% / 15% и обучает `CatBoostRegressor` с ранней остановкой.
6. Проверяет модель на последнем, отложенном периоде и сохраняет артефакты.
7. Запрашивает у Open-Meteo температуру и скорость ветра на высоте 100 м на 48 часов.
8. Возвращает для каждого часа нормализованную мощность. Если задана установленная мощность ВЭС, дополнительно рассчитывает мощность в МВт и энергию в МВт·ч.

Лаги фактической мощности в CatBoost-пайплайн намеренно не включены: прогноз строится по погоде соответствующего будущего часа и календарным признакам.

Значения ниже взяты из сохранённых выводов ноутбуков.

| Эксперимент | Разрешение и тест | MAE | RMSE | Дополнительно |
|---|---|---:|---:|---|
| CatBoost | почасовые данные, 3 731 строка | 0,0204 | 0,0556 | nMAE 2,0422%; R² 0,9759 |
| SimpleRNN | 10-минутные данные, последние 20% (29 900 строк) | 0,046756 | 0,077491 | одномерная история мощности |
| LSTM | 10-минутные данные, последние 20% (29 900 строк) | 0,047301 | 0,077670 | ветер, мощность и температура |

CatBoost и нейросетевые эксперименты используют разную временную гранулярность и разные признаки, поэтому эти числа не являются строгим сравнением моделей в одинаковых условиях. SARIMA исследована как классический baseline, но её полный расчёт на общем тестовом периоде в текущей версии не завершён.

## Данные и интеграции

В репозитории находится `dataset_energy.csv` с 149 499 строками за период с 11 марта 2023 года 00:00 до 31 января 2026 года 23:50. Поля набора:

- `ID`;
- `Статистическое время`;
- `Средняя скорость ветра(m/s)`;
- `Нормализованная активная мощность`;
- `Средняя температура окружающей среды(°C)`.

В сохранённом аудите CatBoost-ноутбука отсутствуют пропуски, полные дубликаты, повторяющиеся временные метки и выходы мощности за диапазон 0–1. Источник, условия получения и лицензия набора данных в репозитории не указаны.

Для оперативного прогноза `lerning_catboost.ipynb` обращается к публичному Open-Meteo Forecast API. Запрос использует координаты `56.742815, 61.084327`, 48-часовой горизонт, температуру на высоте 2 м и скорость ветра на высоте 100 м. Для этого шага нужен доступ в интернет; API-ключ в коде не используется.

## Установка и запуск

Требуется установленный Python 3. Команды ниже выполняются из корня репозитория.

### Windows PowerShell

```powershell
git clone https://github.com/BAITC-Hacks/hack-292e04fe-neurohub.git
cd hack-292e04fe-neurohub

python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install jupyter pandas numpy matplotlib seaborn scikit-learn catboost tensorflow statsmodels openpyxl joblib requests

jupyter lab
```

### Linux/macOS

```bash
git clone https://github.com/BAITC-Hacks/hack-292e04fe-neurohub.git
cd hack-292e04fe-neurohub

python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install jupyter pandas numpy matplotlib seaborn scikit-learn catboost tensorflow statsmodels openpyxl joblib requests

jupyter lab
```

После запуска откройте `lerning_catboost.ipynb`. В его ячейке настроек замените абсолютный `DATA_PATH` на переносимый путь:

```python
DATA_PATH = Path("dataset_energy.csv")
```

Затем выполните ячейки сверху вниз. Обучение RNN/LSTM и особенно SARIMA может занять заметно больше времени, чем запуск CatBoost.

## Как проверить решение

Минимальный воспроизводимый сценарий для жюри:

1. Установить зависимости и запустить Jupyter Lab по инструкции выше.
2. Открыть `lerning_catboost.ipynb` и указать `DATA_PATH = Path("dataset_energy.csv")`.
3. Выполнить все ячейки до раздела «13. Функция применения модели к будущему прогнозу погоды» включительно. Проверить, что построен временной holdout, рассчитаны метрики и создана модель `model_artifacts/catboost_wind_power.cbm`.
4. При наличии интернета выполнить ячейки с запросом Open-Meteo и расчётом `forecast_48h`.
5. Убедиться, что итоговая таблица содержит `datetime`, `forecast_normalized_power`, `forecast_power_mw` и `forecast_energy_mwh` для 48 часов.

В ноутбуке установлен демонстрационный пример мощности станции `50.0` МВт. Это настраиваемое значение, а не подтверждённая характеристика объекта. Для прогноза только в долях 0–1 оставьте `INSTALLED_CAPACITY_MW = None` и используйте функцию `forecast_from_weather` без пересчёта в физические единицы.

В Git уже включены сохранённые модели `catboost_wind_power.cbm`, `rnn_wind_power.keras`, `lstm_wind_power.keras` и CSV с примерами предсказаний, поэтому структуру результата можно изучить без повторного обучения.

## Ограничения текущей версии

- Проект представлен исследовательскими ноутбуками: веб-интерфейса, CLI, серверного API и автоматического расписания прогнозов нет.
- Единого файла зависимостей с зафиксированными версиями нет; воспроизводимость окружения не гарантирована.
- В нескольких ноутбуках путь к датасету задан абсолютным Windows-путём и требует ручной замены.
- CatBoost проверен на наблюдавшейся погоде, а не на архиве погодных прогнозов, реально доступных в момент принятия решения. Такая оценка может быть оптимистичной.
- Координаты Open-Meteo и демонстрационная установленная мощность 50 МВт зашиты в ноутбук.
- Текущий прогноз использует только температуру и скорость ветра; запрошенные направление ветра, порывы и давление моделью не используются.
- Для пересчёта нормализованного прогноза в МВт/МВт·ч нужна фактическая установленная мощность станции.
- Прогноз на 48 часов требует доступности Open-Meteo и интернета; обработка отказов API ограничена стандартной HTTP-ошибкой.
- Сохранённые RNN/LSTM-модели не включают отдельно сериализованные scaler-объекты, что затрудняет применение моделей к новым данным вне ноутбуков.
- SARIMA не обучена до конца на полном наборе и не включена в сопоставимую итоговую оценку.
- Автоматических тестов и CI в репозитории нет.
- Происхождение и лицензия исходного датасета не задокументированы.
